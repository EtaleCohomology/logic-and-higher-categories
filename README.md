# logic-and-higher-categories

Articles on **Rzk, homotopy type theory, ∞-categories and categorical logic**, written by Étale Cohomology.

This repository collects PDF versions of articles originally published on Qiita (in Japanese). The articles explain, for programmers and mathematics learners, how logic, type theory and higher category theory meet: from the many logical systems in use today, through homotopy type theory (HoTT), to Rzk, a proof assistant designed specifically for ∞-category theory.
